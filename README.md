# 한국 기준중위소득 조회기

청약·복지 제도에서 쓰이는 모든 소득 기준을 한 번에 확인하는 Streamlit 웹앱.

## 기능
- 가구원 수 × 비율(50%·100%·120%·150%·200% 등)별 월/연 소득 조회
- 내 소득 입력 → 중위소득 대비 % 자동 계산
- 자격 가능성 있는 청약·복지 제도 자동 매칭
- 가구원 수 1~7+ 전체표 (8인 이상 자동 계산)

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 데이터 출처
보건복지부 중앙생활보장위원회 고시 (매년 7~8월 발표).
연도별 금액은 `data.py`의 `MEDIAN_INCOME` 딕셔너리에서 수동 업데이트.
