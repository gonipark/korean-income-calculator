# 한국 기준중위소득 조회기

청약·복지 제도에서 쓰이는 모든 소득 기준을 한 번에 확인하는 정적 웹앱.

🌐 **배포:** https://gonipark.github.io/korean-income-calculator/

## 기능

- **내 위치** — 월/연 소득 입력 → 중위소득 대비 % 자동 계산
- **상황 진단** — 11문항 위저드로 6개 주요 제도 자격 자동 판정
  (생계급여 · 주거급여 · 청년월세 · 신혼특공 · 청년매입임대 · 디딤돌 대출)
- **비율 조회** — 가구원 수 × %별 월/연 소득 표
- **전체표** — 가구원 수 1~7+ 매트릭스 (8인 이상 자동 계산)

## 로컬 실행

빌드 도구 없이 정적 파일만 있으면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 데이터 출처

보건복지부 중앙생활보장위원회 고시 (매년 7~8월 발표).
연도별 금액은 `data.js`의 `MEDIAN_INCOME` 객체에서 수동 업데이트.
